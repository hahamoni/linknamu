# P04 — 이름이 될 뻔했던 큐브 (래리 니콜스 / US3655201)

14비트 41.8초/34.6초. 게이트 통과 2026-08-27. 구조: **훅(루빅스보다 먼저 나온 큐브가 있었다면?) → 쉬운 설명 → 반전(청구항의 '여덟'이라는 단어 하나가 판을 뒤집었고, 그가 남긴 말).**

반전 축은 두 겹이다. ① 9비트에 심어둔 "여덟 개의 조각"이 13비트에서 그의 발목을 잡는 회수 구조.
② 마지막 한마디 "니콜스 큐브가 될 수도 있었다."

**절대 금지**: "루빅이 베꼈다"는 단정. 법원 기록상 원고 측조차 도용을 주장하지 않았고, 니콜스 본인이
루빅의 독립 발명을 확신한다고 밝혔다. 대본은 "먼저 도착했다"까지만 말한다.
