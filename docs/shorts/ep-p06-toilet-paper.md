# P06 — 휴지 방향, 특허는 정말 답을 말했나 (세스 휠러 / US465588)

14비트 36.9초/33.9초. 게이트 통과 2026-08-27. 구조: **훅(앞으로? 뒤로?) → 쉬운 설명 → 3중 반전.**

이 편은 특이하게 **인터넷 통설 자체를 뒤집는다.** "1891년 특허 도면이 over가 정답임을 증명했다"는
2015년 바이럴이 출발점인데, 1차 자료를 읽으면 세 겹으로 무너진다.

## 반전 구조 (3중)

1. **본문에 방향이 없다** — over/under, 벽, 걸이 어느 것도 명세서·청구항에 없음. 청구항은 ∧자 연결부 하나.
2. **도면에 기준물이 없다** — 롤이 공중에 떠 있어 "벽 기준 어느 쪽"을 판정할 수 없음.
3. **같은 발명가의 1년 앞선 특허에는 벽이 그려져 있고, 거기선 아래로 나온다** (US438567).
4. **결정타(14비트)** — 휠러가 실제로 풀려던 문제는 "어느 방향이 맞느냐"가 아니라 **"어느 방향이든 상관없게"** 만드는 것.
