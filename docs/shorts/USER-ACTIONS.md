### 매일 한 번, 이 한 줄

결제 없이 무료 티어로 가기로 하셨으니 **쿼터가 열리는 시간대에 하루 한 번** 실행하시면 됩니다.
쿼터 리셋은 **매일 07:00 UTC = 한국시간 오후 4시**입니다.

```bash
bash scripts/shorts/run_daily.sh
```

이게 전부입니다. 폰트 경로도, 편 목록도 넘길 필요 없습니다. 나레이션이 덜 찬 편을 알아서
찾아 채우고, 한 편이 다 차는 순간 조립까지 끝냅니다. 429가 나면 모델을 바꿔가며 길게 쉬고
다시 시도합니다. 중간에 끊겨도 **진행분은 파일로 남으니 다음 날 같은 명령을 다시 실행하면
남은 것부터 이어서** 갑니다.

```bash
python3 scripts/shorts/status.py        # 지금 어디까지 왔는지
bash scripts/shorts/run_daily.sh stop   # 중단
tail -f logs/tts.log                    # 진행 로그
```

**며칠 걸립니다.** 남은 건 나레이션 150비트 = 43청크(+P01 영어 2청크)인데, 무료 티어는
모델당 하루 열 번 남짓이라 하루에 열몇 청크가 한계입니다. 사나흘 잡으시면 됩니다.
매일 한 번만 켜 두시면 알아서 쌓입니다.

편 하나만 손으로 돌릴 때:
```
python3 scripts/shorts/chunked_tts.py docs/shorts/ep-pNN-beats.json --lang ko --model gemini-3.1-flash-tts-preview
python3 scripts/shorts/compress_silence.py docs/shorts/ep-pNN_output/beat*_ko.wav
python3 scripts/shorts/assemble.py docs/shorts/ep-pNN-beats.json --lang ko --edit docs/shorts/ep-pNN-edit.json --font <Pretendard-Bold.ttf> --music docs/shorts/ep-pNN_output/music_bed.mp3
```
자리표시 무음 나레이션으로 비주얼만 미리 보려면: `python3 scripts/shorts/placeholder_wavs.py docs/shorts/ep-pNN-beats.json --lang ko`
