# P10 — 그네 타는 법에 특허가 났다 (스티븐 올슨 / US6368227B1)

14비트 41.1초/41.8초. 게이트 통과 2026-08-27. 구조: **훅(그네 타는 법이 특허가 될까) → 쉬운 설명(줄을 번갈아 당기면 옆으로 흔들린다) → 반전(서류를 써준 변리사가 아버지였고, 아들은 낼 때 다섯 살이었다).**

반전 축은 이름 짝이다. 13비트 카드 `Attorney: PETER LOWELL OLSON`, 14비트 카드 `Inventor: STEVEN OLSON`.
같은 성이 두 장 연속 뜨는 것으로 나레이션 없이도 착지한다.

**이 편의 두 번째 반전**: 이 특허를 무너뜨린 건 경쟁자도 소송도 아니라 **특허청 자신**이다.
등록 6주 뒤 커미셔너가 직권(sua sponte)으로 재심사를 걸었고, 14개월 뒤 청구항 네 개가 전부 취소됐다.
