# P03 — 위저 보드가 스스로 지었다는 이름 (US446054)

14비트 44.2초/38.9초. 게이트 통과 2026-08-27. 구조: **훅(영혼의 판, 특허엔 뭐라 적혔나) → 쉬운 설명 → 반전(이름은 그녀 목걸이 속에 있었다).**

반전 축: 판이 스스로 이름을 지었다는 전설 → 그날 이름을 물은 여자의 목에 소설가 **Ouida**의 초상 로켓이 걸려 있었다.
즉 판은 조작자의 머릿속에 이미 있던 것을 뱉었다(관념운동효과). 착지를 하나로 모으기 위해 "잊힌 여자" 서사는 12비트에 배치하고
페이오프는 로켓 하나로 끝낸다.
