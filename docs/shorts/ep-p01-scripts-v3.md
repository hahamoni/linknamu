# P01 대본 v3 — 리라이트 3안 (선택 대기)

v2 피드백 반영: ① 시청자가 배우가 누군지 모름(이름 미공개) ② 반전이 3비트(10초)에서 소진되고 엔딩이 밋밋함.
**v3 공통 원칙: 도입 2초 훅 + 핵심 정보(이름/반전)를 마지막에 배치.** 게이트(2026-08-28) 3안 전부 통과.
비주얼은 기존 확보 자산(스틸 6종·클립 A/B·다이어그램) 재사용 — 대본 교체 비용은 나레이션 TTS 재생성뿐.

주의 표기: 해군 "전쟁 채권" 발언은 ◐(다수 2차 출처, 원문 인용 아님). "블루투스" 연결은 원리(주파수 도약) 계승
서술로만 쓴다 — "그녀가 블루투스를 발명" 단정 금지 (와이파이 필터와 동일 원칙).

## 선택 후 작업

채택안 JSON을 `ep-p01-beats.json`으로 교체 → 나레이션 재생성(chunked_tts, 한·영) → §5 검수 → `assemble.py` 재조립.
비주얼·음악·커버는 그대로. B안 채택 시 커버 문구 교체("가장 아름다운 얼굴의 저주"), C안은 커버 이미지에 다이어그램 요소 혼합 검토.
