## 짚어야 할 것 — 무료 티어의 학습 데이터 문제

Gemini **무료** 티어 약관은 제출 내용과 생성 결과를 "구글 제품 개선에 사용"하고
"사람 검토자가 읽고 주석을 달 수 있다"고 명시한다. **유료로 바꾸면 이 조항이 없어진다.**
월 ₩1,700의 값어치는 속도가 아니라 여기에 있다 — 미공개 대본 12편이 지금은 학습 데이터다.

## Cloud TTS를 들어보려면 — 계정 설정이 필요하다

Cloud TTS는 API 키를 받지 않는다(401 CREDENTIALS_MISSING). 서비스 계정이 있어야 한다.

1. https://console.cloud.google.com 에서 프로젝트 생성
2. **Cloud Text-to-Speech API** 사용 설정
3. IAM → 서비스 계정 만들기 → JSON 키 다운로드
4. `export GOOGLE_APPLICATION_CREDENTIALS=<내려받은 키 경로>`

무료 한도 안에서는 결제 정보를 넣어도 청구되지 않지만, 구글은 보통 카드 등록을 요구한다.
**이 단계가 번거로우면 Gemini 유료 전환(월 ₩1,700)이 더 간단하다** — 키를 이미 쓰고 있고
코드를 한 줄도 안 고쳐도 된다.
