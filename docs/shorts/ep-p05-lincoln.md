# P05 — 아무도 쓰지 않은 발명품 (에이브러햄 링컨 / US6469)

14비트 40.9초/34.6초. 게이트 통과 2026-08-27. 구조: **훅(아무도 쓴 적 없는 발명품) → 쉬운 원리 설명 → 반전(특허를 가진 유일한 미국 대통령).**

핵심 연출 장치: **1비트에 1846년 다게레오타입(수염 없는 링컨)을 쓴다.** 대중이 아는 수염 난 링컨과 얼굴이 달라
마지막 비트 전까지 정체가 드러나지 않는다. 13비트에서 수염 난 1860년 초상으로 바꿔 반전을 시각적으로 완성.
